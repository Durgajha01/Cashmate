# Cashmate

Cashmate is a comprehensive AI-powered financial management and tracking application designed to help users monitor expenses, analyze financial models, and optimize cash flows.

This demo video provides a step-by-step explanation of how the CashMate system works, demonstrating its workflow, key features, and overall functionality. It offers a clear overview of the system and explains how users can interact with it.

https://github.com/user-attachments/assets/35dc70c3-b23d-4e74-a9f8-76ac83fa4637


## Project Structure

- **`frontend/`**: Next.js & React frontend for intuitive financial dashboard and tracking interfaces.
- **`financial-model/`**: Python-based AI financial modelling backend and calculations engine.

## Getting Started

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### Financial Model Setup

```bash
cd financial-model
python -m venv venv
# On Windows:
.\venv\Scripts\activate
# On Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
```
